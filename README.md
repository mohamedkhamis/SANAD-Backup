# SANAD Backup

Backup and recovery for Microsoft SQL Server on Windows: scheduled backups, restores, cloud destinations and
notifications, with a desktop app, a web dashboard and a command-line tool.

**Download:** [sanad.khamis.work/download](https://sanad.khamis.work/download), or from
[Releases](https://github.com/mohamedkhamis/SANAD-Backup/releases).

Each release has:

- `SanadSetup-<version>.exe`: the setup program (it also installs the Microsoft Edge WebView2 Runtime when it is missing);
- `Sanad.Setup-<version>.msi`: the Windows Installer package, for `msiexec` and Group Policy.

Each release's notes list the SHA-256 checksums of its files. Requirements: Windows 10 version 1809 (build 17763)
or later, or Windows 11; x64.
